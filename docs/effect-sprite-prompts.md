# Lyric effect frame assets

Tool mode: built-in `image_gen.imagegen`, transparent PNG sprite atlases. Original generated files are preserved. Each atlas contains 16 independently drawn animation frames.

Atmosphere expansion: `docs/atmosphere-effect-prompts.json` records all nine selected generated sheets, full prompts/refinements, source files, content hashes and layout/event rules. Twenty additional choices share moon, star, meteor, snowflake, petal, golden leaf, ribbon and butterfly cels, together with the existing sun, clouds and birds. The new `storm-cloud-v2.png` joins the cloud and discharge in one source frame; quiet and active draws meet at the same source seam. One to three cloud sites remain in fixed positions, while seeded sparse flashes switch sites without repeating the last one. A second site is used only once per five long episodes. Normal clouds rise by `.08 × lyric height`. All floating subjects remain smaller than the letters, with no more than three at a time. New role bindings use renderer v10; old rain/lightning role bindings still parse. Playback exports include only used PNG bodies, once per content ID.

Fire-only alignment correction: its horizontal source cels place more mass above the emitter than the angled bolt. A `.045 × lyric height` downward root compensation aligns its visible center to lightning in the shared canvas painter. Frame images, scale, source orientation and the lightning placement remain unchanged.

Final selected assets:

Full generation and refinement prompts for the three nature presets are recorded in `docs/nature-effect-prompts.json`. All atlases retain the generated transparent pixels; each is smaller than 1 MB. The existing fire/lightning artwork and text palettes are retained. Each new text theme starts pale and wipes to a darker pink, green or rain blue. Weather components and their full prompts are recorded in `docs/weather-effect-prompts.json`: one white cloud atlas, one overcast cloud atlas, one sun atlas and one bird atlas. Rain streaks reuse the existing approved sheet; the expanded storm now uses its joined cloud/discharge atlas described above. Sky objects remain inside their selected group, at most three at a time, smaller than the lyric height, with muted opacity and only `.35 × lyric height` of extra row headroom. Cloud boxes are `.85 × .5` lyric height at 55% opacity, suns `.48–.52` square at 65%, and birds `.68 × .4` at 60%. Each shared bitmap is packaged once by its content ID even when different type/role bindings need it. Standalone fire/lightning and plain rain retain their approved artwork, colors and geometry.

Older thick trials and the burning strip were removed; the approved branching fire remains as a fallback. The new fire has one substantial continuous body and no lightning-like branches. It already faces outward and uses translation/mirroring without rotation. Its connected lower-left root is anchored to the glyph, ignoring detached alpha residue. The common emission size remains `.66 × lyric height`; compact fire uses length multiplier `.92` and height multiplier `.63` to fit the same visible footprint as the rotated lightning. Both retain the raised glyph attachment (`rootRise: .24`). Text, images, GIFs and effects share the presentation canvas. Playback exports package only the active used atlas for each effect, once each, without the backup or any base-strip assets.

## Preserved branching fire — original lightning-style reference

```text
Use case: stylized-concept
Asset type: a production transparent PNG sprite atlas for flame effects on karaoke text.
Reference image role: approved LIGHTNING atlas. Match its elegant thin branching channels, ink thickness, pointed tips, restrained three-color treatment and visual mass. Convert that visual language into FIRE, not a round campfire or oval flame blob.
Draw EXACTLY 16 consecutive animation cels arranged in a clean 4×4 grid. Each cell is a connected energetic flame discharge with a fixed emitter root at x=18%, y=63%, flowing outward to the RIGHT and gently upward. Main flame ends at x=83%, y=35%; two small branching flame tongues reach upward/downward from its bends. Draw the horizontal outward orientation directly. Keep the same overall occupied bounds and channel thickness in every cel. Re-sculpt the flame bends, branch tips and hot inner currents in each cel so the loop feels like fast living heat. Frame sixteen flows into frame one.
Design: slender angular branching flame channels, slight fluid curves at the flame tips, negative-space gaps between branches. The connected shape and three thin nested color bands should have almost the SAME thickness and area as the reference lightning. Clean pointed flame forks, no rounded bulbous body, no wide solid white/yellow center. Orange outer channel (#ff8700), golden yellow middle (#ffc43b), narrow pale cream hot channel (#fff0b0). Think of the reference's blue/cyan/white energy rendered as orange/gold/cream burning energy. Minimal detail, crisp contemporary cel artwork, professional game effect.
Background: actual fully transparent alpha outside the main connected channels; clear gutters between all cells. No glow, airbrush haze, textures, speckles, smoke, sparks, detached particles, floor/base platform, frame, badges, grid lines, labels, text or watermark. No long thin streamer and no chunky cute flame icon. Preserve the reference's balanced sharp branching design and approximate stroke weight.
```

## Lightning — retained prompt

```text
Use case: stylized-concept
Asset type: production transparent PNG sprite atlas for a lyric text animation.
Composition: EXACTLY 4 columns by 4 rows, 16 equally sized square cells. Each cell is ONE independently drawn consecutive animation frame. Read left to right, top to bottom. No labels or grid lines. True transparent background with completely clean alpha, no background tint or scattered noise. All artwork strictly inside each cell with 8% clear margins. Every frame has the SAME fixed narrow emitter root at x=50%, y=90% within its cell, pointing upward. Same overall length and occupied bounds in ALL 16 frames; no growing then shrinking whole object. Create a continuous energetic loop by redrawing moving contours and internal shapes, not rotating or translating a static image. Frame 16 naturally flows into frame 1.
Style: refined contemporary flat animation cel art, bold fluid silhouettes, few clean shapes and only three flat colors. Less detail. No realism, no glow, no airbrush, no texture. Professional stylized game motion, not a cute icon.
Constraints: NO floor, base platform, oval puddle, shadow, outline stroke, detached floating particles, badge, text, logo, border or watermark. This is an emitting jet attached to a letter, NOT a standing campfire/sticker. A thin tapered root expands into the plume above; the root itself must be narrow enough to merge into a letter stroke.
Primary request: sixteen consecutive cels of a forceful electric discharge emerging from a narrow fixed root. A lean fast zigzag bolt with two small branching arcs, blue outside, cyan inside, a thin white hot channel (#078eff, #32dcff, #f3feff). Use the reference ONLY for the clean three-color treatment; replace the broad standing burst with a slim emitting arc. Keep each frame a full-length strong discharge. Change the zigzag path and branching topology substantially every frame so it crackles rather than sways. Three to five crisp directional bends, clean purposeful shapes, minimal detail. Body occupies about 70% of cell height, 40% width, root only 6% cell width.
```
